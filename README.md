# rust-hexdump-tui

Интерактивный консольный просмотрщик шестнадцатеричных дампов (Hex Viewer) на Rust.

## Возможности
- Классический 16-байтный вывод (Смещение : Hex-байты : Текстовое представление ASCII).
- Встроенный инспектор базовых типов данных по выбранному смещению:
  - `u8`, `i8`, `u16 (little-endian)`, `u32 (little-endian)`, `f32 (float)`.
- Поддержка просмотра с заданного смещения (`--offset <N>`) и ограничения длины (`--length <N>`).
- Мгновенная работа с большими файлами благодаря буферизованному чтению.

## Сборка
```bash
rustc -O src/main.rs -o releases/rust-hexdump-tui.exe
```

## Использование
```bash
./releases/rust-hexdump-tui.exe <файл> [offset] [length]
```
Если запустить без параметров, анализирует собственный исполняемый файл.
